# Requests for Comments (RFCs)

This directory contains collaborative engineering proposals and exploratory design studies for `ed-schema`.

## Lifecycle & Status

RFC documents progress through the following statuses:

1. **Draft:** Under active development and internal review.
2. **Review:** Open for stakeholder commentary and feedback.
3. **Accepted:** Consensus reached; promoted to an Architectural Decision Record (`architecture/adr/`) or Software Design Document (`architecture/designs/`).
4. **Deferred:** Viable idea postponed due to scope or capacity constraints.
5. **Rejected:** Explored and dismissed with rationale preserved for historical context.

## Document Structure

- **Summary:** Concise high-level proposal.
- **Motivation:** Problem statement and why existing subsystems are insufficient.
- **Detailed Specification:** Technical mechanics, data models, and API signatures.
- **Drawbacks & Risks:** Disadvantages, breaking changes, and migration burdens.
- **Prior Art & Alternatives:** External references and alternative designs evaluated.
