# SDD-007: Code Generation Identifier and Module Filename Sanitization Architecture

## 1. Introduction and Architectural Motivation

### 1.1 Scope and Objective
This Software Design Document (SDD) outlines the technical implementation plan for sanitizing output module filenames and field attribute identifiers generated by `DatamodelCodeGeneratorAdapter` and `CompileDataclassesUseCase`.

### 1.2 Problem Context
When processing upstream schemas such as EDDN `journal-v1.0.json`:
1. The generated output file was named `journal-v1.0.py`. This contains hyphens and dots, preventing standard Python module imports (`import generated_dtos.eddn.journal_v1_0`).
2. The property `$schemaRef` was sanitized to `_$schemaRef: str`, which is invalid Python syntax because `$` cannot appear in a Python identifier. Attempting to load the generated module results in `SyntaxError: invalid syntax`.

## 2. Technical Specification & Implementation Plan

### 2.1 Identifier Sanitization Algorithm
In `src/ed_schema/adapters/driven/codegen/datamodel_code_generator_adapter.py`, introduce an isolated helper method:

```python
import keyword
import re

def _sanitize_identifier(name: str) -> str:
    """Sanitizes an arbitrary schema property name into a valid Python identifier."""
    # 1. Strip leading $ or common symbols
    clean = name.lstrip("$")
    # 2. Convert non-alphanumeric characters to underscores
    clean = re.sub(r"[^0-9a-zA-Z_]+", "_", clean).strip("_")
    # 3. Fallback for empty strings
    if not clean:
        clean = "field"
    # 4. Handle leading digits
    if clean[0].isdigit():
        clean = f"field_{clean}"
    # 5. Handle Python keywords (e.g. 'class', 'from', 'import')
    if keyword.iskeyword(clean):
        clean = f"{clean}_"
    return clean
```

### 2.2 Module Filename Normalization Algorithm
In `CompileDataclassesUseCase` (`src/ed_schema/core/use_cases/compile_dataclasses_use_case.py`) and `DatamodelCodeGeneratorAdapter`:

```python
def _normalize_module_filename(schema_path: Path) -> str:
    """Normalizes a schema filename into a valid Python module filename (e.g. journal_v1_0.py)."""
    stem = schema_path.stem
    clean_stem = re.sub(r"[^0-9a-zA-Z_]+", "_", stem).lower().strip("_")
    if not clean_stem:
        clean_stem = "schema_model"
    elif clean_stem[0].isdigit():
        clean_stem = f"model_{clean_stem}"
    return f"{clean_stem}.py"
```

### 2.3 Class Title Extraction Normalization
Enhance class title derivation to handle stems with hyphens and dots properly:
```python
stem = schema_path.stem
clean_parts = re.split(r"[^0-9a-zA-Z]+", stem)
title = "".join(part.capitalize() for part in clean_parts if part)
```
